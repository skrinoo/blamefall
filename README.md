# 锅从天降 · BlameFall

> **一款教你甩锅的爽游，和一堂教你接锅的课。**

60 秒一局。锅从天上掉下来，你得在落地前把它甩给某个人，并当场给出一个理由。
写得越好，甩得越远；甩错了人，锅会弹回来，心理阴影面积还会涨。

**零构建、零依赖、零安装，双击 `index.html` 就能玩，断网也能玩。**

---

## 立即试玩

**最简单的方式**：用浏览器打开 `index.html`。

```
双击 blamefall/index.html
```

没有 `npm install`，没有构建步骤。本项目全部用经典 `<script>` 而不是 ES module ——
因为 `file://` 协议下 module 会被 CORS 拦掉，而这个游戏必须做到「下载下来双击就能跑」。

### 在线试玩（已部署）

| 链接 | 说明 |
|---|---|
| `https://skrinoo.github.io/blamefall/` | GitHub Pages 镜像（大陆可达），纯静态、自由输入自动降级本地兜底裁判 |
| `https://blamefall-yy3a.vercel.app/` | Vercel 完整版（含 AI 后端 `/api/*`），`*.vercel.app` 在大陆网络波浪式间歇封锁 |

> 部署态与 `file://` 双击态的玩家体验一致：页面通过 http(s) 打开时会**自动**把
> `apiBase` 指向自己的 origin，`file://` 下则保持离线。详见 [`docs/DEPLOY.md`](docs/DEPLOY.md)。

### 两种形态

| 形态 | 怎么跑 | 自由输入由谁判 | AI 生成锅 |
|---|---|---|---|
| **离线** | 双击 `index.html`（`file://`） | 本地兜底引擎 | 无（静态锅池 17 口） |
| **在线** | 通过 http(s) 提供（部署态，或 `scripts/dev-server.ps1`） | 真 AI 裁判 `/api/judge` | 有（`/api/genpot` 预生成缓冲） |

两种形态共用同一套判定公式与文案库，只是「自由输入」这一条路径的裁判从本地兜底引擎
换成真 AI。快速选项永远走 0ms 查表，与形态无关。

## 游玩方法

### 四个动词（核心操作）

| 动词 | 操作 | 效果与代价 |
|---|---|---|
| **抓** | 点击空中的锅 | 时间减速到 0.3 倍，但有 **12 秒**真实时间的握持预算，超手就滑 |
| **甩** | 抓着锅点某个 NPC | 锅飞过去；消耗一次甩锅机会，对方会疲劳 |
| **辩** | 选一种论证方式 | 快速选项查表（0ms），或自己打字（走 AI 判定） |
| **接** | 点自己 | **隐藏动词**。不得分，心理阴影 −8，接锅信用 +1 |

### 五种论证（「辩」的语法）

```
事实型  援引客观事实、记录、已有分工        「这部分是他上周认领的」
情感型  援引自己的状态、付出、情绪          「我这几天真的已经尽力了」
转移型  援引流程、制度、职责边界            「这个环节本来就没人明确负责」
反向型  把对方的行为当作自己行为的原因      「是您让我这么做的」   ← 需接锅信用 ≥ 3 解锁
荒诞型  援引无法证伪的玄学、超自然前提      「水星逆行」
```

前四种是「把话说圆」，荒诞型是「把话说飞」——它几乎必败，但永远好笑。

### 设置面板（⚙）

- **玩法**：场景契合软过滤开关（发光 = 这口锅真牵扯到 TA）、自由输入读秒（0 / 12s / 24s）
- **声音**：BGM 音量 / 音效音量（暂停时 BGM 自动降低）
- **主题**：光亮版（默认）/ 暗版，切换即时生效，背景/头像/图标/特效全跟随
- **AI**：AI 裁判 / AI 生成锅总开关 + 可选填自己的网关 Key 与模型 ID

### 快捷键与调试

- 按 <kbd>`</kbd> 呼出**开发者面板**：看每次判定的 P / S / A / G 实算过程、文案来源（查表 / AI / 兜底）
- 面板内置「显示 S/A/G/P」「半速」「不掉血」「立即结算」等调试开关
- 快速选项可用键盘 <kbd>1</kbd>–<kbd>5</kbd> 选择（对应五种论证类型）；抓住锅未开面板时按数字键 <kbd>1</kbd>–<kbd>9</kbd> 可直接选中对应 NPC

## 游玩内容

### 四幕节奏（60 秒）

| 幕 | 时间 | 名字 | 变化 |
|---|---|---|---|
| 第一幕 | 0–20s | **爽** | 锅掉得慢、接受度 +12，让你先爽起来 |
| 第二幕 | 20–40s | **紧** | 掉速加快、同时空中的锅变多，加成归零 |
| 第三幕 | 40–55s | **高潮** | 锅倾泻而下，环阵汇聚，接受度转负——谁都开始不接 |
| 第四幕 | 55–60s | **结尾** | 最后一口锅悬停，逼你面对那个没有甩给任何人的自己 |

### 五种结局

成功 / 失败 / **被反甩**（锅弹回来砸你）/ **延期交付**（甩给未来的自己，本局不扣分，下一局锅变多）/ **悬空**（辅导员既不接也不拒，把这件事按住了）。

### 结算卷宗

结算页给出你的**段位评语**、甩锅得分、心理阴影面积，以及一份数据驱动的
**「甩锅体质报告」和「防甩锅手册」**——哪些人你欺负得最顺手、哪些理由你用得最顺嘴，全都有据可查。

## 游戏内核价值

这不是一个「甩锅越多分越高」的游戏。

**心理阴影面积**从 12 开局，上限 100，满了就崩溃、本局提前结束。甩锅成功会加阴影，
加多少取决于你甩给了谁：

- 甩给**学弟学妹**（最好甩）—— 得分最低，阴影 **+2**（欺负老实人的代价）
- 甩给**天气 / 水逆 / 星座** —— 永远成功，永远只值 30 分，阴影 **0**（无主体的锅最便宜也最空）
- 甩给**导师**（难度最高）—— 常规路径根本推不动，但得分最高

**接锅是全游戏唯一能降低阴影的手段。** 它不得分。

于是玩家会自己发现一件事：

> **得分最高的策略，和让你活到最后的策略，不是同一个。**

游戏全程不说教。它只是把这两条曲线画在你面前，让数值自己讲话。
甩锅失败现在也不是「白费一次」——它会扣 15 分、涨阴影；甩给已经进入冷战的人，
更要付出双倍代价。每一次乱甩，都在账上记一笔。

### 那个「漂亮的设计涌现」

判定公式是：

```
P = S × 0.4 + A × 0.4 + G × 0.2          P ≥ 0.6 → 甩锅成功

S  说服力 (0-100)   这个理由本身的论证质量
A  接受度 (0-100)   对方此刻愿不愿意接
G  锅归属 (0.0-1.0) 这口锅本来该不该他背
```

全库组合跑下来，**P 值最高的那一次不是最好甩的，而是最有事实依据、锅归属最清晰的
那一次**（`trash → 室友 · 事实型`，P = 0.82）。

游戏在数值层面奖励「厘清责任」、惩罚「欺负老实人」，一句台词都没写。

## 游戏设计逻辑

### 三条铁律（撞了四次才学全）

> **凡是可以查表或可以用规则算出来的确定性游戏数据，一律不让 LLM 输出。**
>
> LLM 只负责三件事：理解自然语言论证的质量、为一种行为命名、写一句有洞察的点评。

四次失败的完整记录（`moral_cost` 漂移 → `argument_type` 漂移 → `pot_ownership` 错判
→ `power_success` 把荒诞型评成全场最强）见 [`docs/DEVLOG.md`](docs/DEVLOG.md) 第 3 节。

### 关键设计取舍

- **反向型是「接锅换来的资格」**：一个从不承担责任的人说「是你让我做的」是推诿；
  接过三口锅的人说这句话是陈述事实。数值上，解锁后对方无法再以「你凭什么这么说」驳回你。
- **快速选项封顶**：完美论证暴击只能由玩家亲手写出的自由输入触发——否则 0ms 查表也能暴击，
  自由输入就失去了意义。
- **抽象 NPC 永远成功但得分 ×0.3**：甩锅给天气/水逆/星座没有阻力，也没有分量。
- **前女友只接「点名到 TA」的锅**：靠 `cast` 字段判定，AI 造的场景标签对不上也会正确弹回。
- **接锅是隐藏动词**：标题屏不教，全靠玩家自己发现。它是全游戏唯一的阴影负增长手段，
  也是解锁反向型的唯一途径。

## 游戏架构

### AI 不在热路径上

快速选项的理由文本是**写死的**，所以它的判定结果可以在构建期一次性生成，运行时纯查表：

| | 调 AI | 查表 |
|---|---|---|
| 延迟 | ~800ms | **0ms** |
| 成本 | 每次约 130 tokens | **0** |
| 断网 | 不可玩 | **可玩** |

实测约 **90% 的操作走查表路径**。只有「自由输入」才真的调 `/api/judge`。

> **锅也可以由 AI 生成**：接入 key 后，`/api/genpot` 在后台预生成带 `targetRole` 标注的新锅，
> 客户端 `engine/potgen.js` 把它们缓进缓冲；甩锅那一刻仍从缓冲 **0ms 取用**，
> AI 只在「需要之前」跑，铁律不破。没接 key（`file://` 直开）就是冷路径，全用静态锅池。
> 生成失败 / 超时 / 坏批一律静默落回静态锅。

```
data/verdicts.js    59 条判定库 + 每种论证类型 3 条通用兜底（共 15 条）
engine/fallback.js  说服力 S 对固定文本实算（关键词表 + 长度 + 类型匹配 + 公文腔加成）
engine/judge.js     P 公式、完美论证暴击、五种结局、冷战/反甩/悬空/延期分支
engine/api.js       只管自由输入；返回值只有「通过全字段校验的对象」或 null
engine/audio.js     四幕 BGM 循环 + 切幕自动换曲 + 音效（whoosh/catch/slip/ending/blame/click）
engine/potgen.js    AI 锅预生成缓冲（热路径取用 / 冷路径兜底，与 genpot.mjs 同源校验）
api/genpot.mjs      GET/POST /api/genpot：让网关生成 n 口锅，服务端逐口洗成引擎可用的 def
api/probe.mjs       GET/POST /api/probe：拿玩家的 key+model 真调一句极简 prompt，回答「能不能用」
fx.js / fx.css      特效层：命中火花 / 冷雾爆开 / 冰化 / 甩锅拖尾 / 环阵光束 / 终幕灰烬
```

`api.js` 的契约是：**「有返回」不等于「可用」**。超时 / 网络错 / 空响应 / JSON 坏 /
字段越界，一律返回 `null`，上层切本地兜底引擎，玩家侧完全无感。超时的响应即使后到也
**必须被丢弃**——否则会出现「气泡已经显示兜底文案，半秒后又被 AI 文案覆盖」的闪烁。

### 自带 API Key 与选模型（可选）

标题屏「AI 裁判 / 生成锅」设置区：**一个 AI 总开关** + 玩家可填自己的网关 Key 和模型 ID。

| AI 开关 | Key | 实际版本 | token 记在 |
|---|---|---|---|
| 关 | 任意 / 留空 | 无 AI 判定 + 无 AI 生成锅（纯本地兜底 + 静态锅） | 不消耗任何 token |
| 开 | 留空 | 有 AI 判定 + AI 生成锅（作者兜底） | 作者网关账户 |
| 开 | 填了 | 有 AI 判定 + AI 生成锅（玩家凭据） | 玩家网关账户 |

> **作者兜底 AI 只在有后端的部署（Vercel）上生效**：GitHub Pages 是纯静态、没有 `/api`，
> 那里无论开关如何都是无 AI 版。开机先 `GET /api/health` 探测后端真伪与作者有没有配 key，
> badge 据此显示真实状态（如「该部署无后端 · 本地兜底 + 静态锅」），**不会谎报**。

其余细节：

- **Key 记在自己账上**：填了之后请求带 `x-bf-key` / `x-bf-model` 头，服务端优先用请求级凭据；
  留空则回落服务端环境变量（作者兜底）。**`base` 始终只认环境变量**——允许请求改 `base` 等于开放 SSRF，不做。
- **首次打开才提醒**：Key 存 `localStorage`（`bf.apiKey` / `bf.model`），只存玩家自己浏览器，不上报任何地方。
- **选模型 + 检测可用性**：「检测」按钮打一次 `/api/probe`，失败也返回 200（`ok:false` + 错误码），
  前端把错误码翻译成提醒（401 Key 无效、402 余额不足、404 模型不存在……）。

## 重新生成判定库（可选）

判定库已经落盘并且人工精修过，**不重新生成也完全能玩**。
如果你想用自己的 key 重跑一遍：

```powershell
# 1. 密钥只从环境变量读，脚本里不出现任何明文
$env:BLAMEFALL_API_BASE = 'https://your-gateway/v1'
$env:BLAMEFALL_API_KEY  = 'sk-...'

# 2. 先空跑，看会生成哪些组合、prompt 长什么样（不发起任何网络请求）
cd blamefall/scripts
.\generate-verdicts.ps1 -DryRun

# 3. 真跑
.\generate-verdicts.ps1

# 只重做某几个 NPC
.\generate-verdicts.ps1 -Only daoshi,ex -Force
```

产物是 `data/verdicts.generated.js` 和 `docs/generation-report.md`。
**它不会覆盖 `data/verdicts.js`**——那一份是人工精修的线上版本，两者并排存在，由人决定采纳哪些。

脚本会用字段名黑名单（`power|score|persuas|rate|prob|rating|weight`）拦下任何数值字段：
**模型只要敢打分，条目就被丢弃并记进失败报告。**

> 兼容 Windows PowerShell 5.1 与 PowerShell 7。
> `.ps1` 文件必须保存为 **UTF-8 with BOM**，否则 5.1 会按系统 ANSI 代码页读取，中文全成乱码。

## 自检

`game.js` 每次开局会跑 `selfTest()`：四条判定案例，期望值写死在代码里。

```
ppt      → 学弟学妹 · 事实型   S=70   expect P=0.70
ppt      → 导师     · 反向型   S=65   expect P=0.28    （前提：接锅信用 ≥ 3）
electric → 水逆     · 荒诞型   S=15   expect P=1       （抽象 NPC 跳过判定）
trash    → 室友     · 事实型   S=85   expect P=0.82
```

引擎或数据表一改，期望值对不上就当场报错。

> 这四条原本是写在 `prompts/judge-v3.md` 里的**手算表格**，后来发现手算错了三处，
> 于是改成可执行断言：**能用断言表达的东西，就不要用文档表格表达。**

平衡性不靠试玩验证——一局 60 秒只覆盖极小部分组合。每次改公式都把全部组合跑一遍，
数据见 `prompts/judge-v3.md` 第 5 节。

## 安全

- 仓库里**没有任何密钥**。批量生成脚本与服务端只从环境变量读取，`.env.example` 只有变量名和空值。
- `file://` 双击态下 `apiBase` 为空 = **离线模式**，游戏不会发出任何网络请求。
- `/api/health` 与 `/api/judge` 的错误响应**不含任何配置值**，只报告「配没配」的布尔。
- 静态文件服务做了路径穿越防护，`..%2f` 编码穿越会被挡成 403。
- `BLAMEFALL_ALLOW_ORIGIN` 可挡住扫公开端点的脚本，但它**不是安全边界**（Origin 头可伪造），
  真正的防线是网关侧配额。
- **请求级凭据覆盖**：玩家自带的 `x-bf-key` / `x-bf-model` 只决定用哪个 key、哪个模型，
  **`base` 恒等于环境变量**（不接受请求级 `base`，杜绝 SSRF）；玩家 Key 只存自己浏览器的
  `localStorage`，服务端不回显、不记日志、不进任何响应体。
